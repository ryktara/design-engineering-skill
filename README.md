# MYownSkills

Private Claude Code skills workspace.

| Path | What |
|---|---|
| `design-engineering/` | The skill: context-first UI/UX design engineering for web, mobile, desktop, TV, and kiosk. Install per `design-engineering/docs/INSTALL.md`. |
| `research/UPSTREAM-AUDIT.md` | Reverse-engineering of nextlevelbuilder/ui-ux-pro-max-skill (architecture, retrieval, knowledge model, activation, context cost, generic-design risk, engineering weaknesses). |
| `research/NEW-ARCHITECTURE.md` | Decisions and rejected alternatives for the new skill. |
| `research/UPSTREAM-VS-NEW.md` | Honest comparison, including where upstream is stronger. |
| `research/BENCHMARK-RESULTS.md` | Generated by `design-engineering/evals/benchmark_upstream.py`. |
| `NOTICE-SOURCES.md` | Licence and provenance: what was inspired, reimplemented, or new; nothing copied. |
| `research/PHASE2-BASELINE.md`, `research/PHASE2-RESULTS.md` | Phase 2 hardening: baseline, requirements contract, facet-aware retrieval, held-out and activation results, regressions. |
| `research/PHASE4-BASELINE.md`, `research/PHASE4-RESULTS.md`, `research/PHASE4-CONCEPT-AUDIT.md`, `research/PHASE4-PROJECTS.md` | Phase 4: scope and intent models, concept ontology, codebase-aware direction, 15 real-project tasks (`research/phase4-projects/`), blind held-out v3 with pre-registered thresholds and human bundle review. |
| `research/PHASE5-BASELINE.md`, `research/PHASE5-RESULTS.md`, `research/PHASE5-PROJECTS.md` | Phase 5: platform semantic resolution, task/mode semantics v2, expected-concept generalisation (aliases, concept trace), native design-context extraction; 22 real-project tasks over 12 codebases on a frozen build (`research/phase5-projects/`), blind held-out v4 (434 cases, three separated roles, two model families) with pre-registered thresholds. |
| `research/PHASE3-BASELINE.md`, `research/PHASE3-RESULTS.md`, `research/PHASE3-FAILURE-TAXONOMY.md`, `research/KNOWLEDGE-AUDIT.md` | Phase 3 generalisation: concern model, guidance bundle, torture tests on nine real projects (`research/phase3-projects/`), blind held-out v2 with pre-registered thresholds. |
| `research/KNOWLEDGE-GAPS.md`, `research/LEXICON-GAPS.md` | Failure-driven gap reports from the frozen held-out and activation sets. |
| `research/runs/` | Archived evaluation runs (held-out v1 runs 1–4, held-out v2 run 1, activation runs, freeze snapshot, k experiment, output size, knowledge audit). |

Quick start:

```bash
python design-engineering/evals/release_check.py            # validator + development + regression + activation proxy + perf sanity
python design-engineering/evals/release_check.py --heldout-v1 --heldout-v2 --heldout-v3 --heldout-v4 --human-review research/runs/heldout-v4-human-review.json --projects  # held-out sets and project rounds (report only)
python design-engineering/scripts/advise.py requirements "Build an Android TV EPG in Compose." --pretty --explain
python design-engineering/scripts/advise.py direction "IPTV home screen for Android TV" --explain
```
